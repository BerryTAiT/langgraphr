How one graph$invoke() call works in langgraphr

flowchart TD
    A["STEP 1
Write your graph in R
(each node = one of your R functions)"]
    B["STEP 2
lg_compile()
sends the blueprint to the Python server"]
    C["STEP 3
graph$invoke('question')
sends the question to start the run"]
    D["STEP 4
Python starts the run,
pauses at the first node,
sends the current state to R"]
    E["STEP 5
R runs YOUR node function
(lg_call_model() talks to the LLM here)"]
    F["STEP 6
R sends the result + next-node
choice back to Python"]
    G{"STEP 7
Any more nodes?"}
    H["STEP 8
A node said '__end__',
so Python sends the final state back"]
    I["STEP 9
You read the answer:
res$state$answer"]

    A --> B --> C --> D --> E --> F --> G
    G -->|"yes: next node pauses"| E
    G -->|"no"| H --> I
